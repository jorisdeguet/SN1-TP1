Ceci est le dépôt de départ pour le TP1

Vous trouverez 3 fichiers:
- racine.py contient le module de calcul de la racine (carré, nième ...)
- test.py contient les tests que vous mettrez en place pour tester déboguer valider votre code (on veut exécuter souvent quand on code)
- evaluation.py contient des appels au module de base que le prof va utiliser pour valider si ton code remplit les consignes
